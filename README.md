# Цифровая лаборатория хаоса

Статический многостраничный образовательный сайт. Откройте `index.html` в браузере или опубликуйте содержимое репозитория через GitHub Pages.

## Структура

- `index.html` — главная страница;
- `pages/` — тематические разделы;
- `css/style.css` — общая дизайн-система;
- `js/` — общая логика и модули интерактивных моделей;
- `assets/` — изображения и иконки.

## Централизованные научные данные

- `data/glossary.js` — единая база терминов и определений;
- `data/formulas.js` — единый каталог формул, переменных и интерпретаций.

При добавлении новой лаборатории нужно проверить новые термины и формулы и внести их в эти базы. Определения и описания формул не следует дублировать в HTML-страницах.

Каждая новая лаборатория также должна содержать интерактивный блок «Вопрос для вывода» с раскрываемым научным ответом и пояснением.

## Команда виртуальных помощников

- `data/assistantCharacters.js` — персонажи, роли и изображения;
- `data/assistantDialogues.js` — централизованные реплики по страницам;
- `data/assistantTriggers.js` — контекстные события появления;
- `js/assistant.js` — единый компонент помощника и сохранение настроек через `localStorage`;
- `pages/team.html` — страница команды лаборатории.

На экране одновременно показывается только один помощник. Новые реплики и триггеры следует добавлять в централизованные файлы данных, а не в HTML лабораторий.
